معالجة البيانات اليدوية والآلية
================================

افتح:
  index.html

أو:
  python serve.py
ثم:
  http://localhost:8771

التنقل
------
أسهم لوحة المفاتيح، أزرار السابق/التالي، أو السحب على الشاشة.
F أو زر ⛶ لملء الشاشة.

المحتوى
-------
1. الموضوعان: يدوية وآلية
2. جودة المدخلات (GIGO) وآلة حاسبة تفاعلية
3. الحاسوب ينفّذ ولا يقرّر إلا إذا بُرمج
4. أمثلة الشركات + صور
5. متى نختار كل نوع
6. مصطلح RFID
7. تحدّي 16 صورة: يدوية أم آلية؟

المصدر: الوحدة 1 — أنظمة تكنولوجيا المعلومات (الإستراتيجية والإدارة والبنية الأساسية)
